# Steam Workshop Publishing Checklist

## Before Upload

- Confirm the mod builds successfully for RimWorld 1.6.
- Keep `About/Preview.png` below 1 MB.
- Check `About/About.xml` for the correct name, package ID, version, dependencies, and supported version.
- Test the mod with a clean RimWorld 1.6 profile.
- Test a new game, Stargate dialing, travel, world-map access, caravan travel, save/load, and return travel.
- Make sure `STEAM_WORKSHOP_DESCRIPTION.txt` contains the final Workshop description.

## Steam Workshop Item

Recommended title:

`RIMWORLD-STARGATE: Parallel Gates`

Recommended visibility during the first upload:

`Unlisted` for a private test, then `Public` after the author confirms the page and required items.

Add these Required Items on Steam Workshop:

- Harmony
- Humanoid Alien Races
- Odyssey DLC support item, if Steam exposes it as a required item

Recommended tags:

- 1.6
- Factions
- Races
- New Content
- World Map
- Exploration
- Gameplay

Use `STEAM_WORKSHOP_DESCRIPTION.txt` as the item description. Keep the first paragraph and the Requirements section at the top so players see them before subscribing.

## First Community Test

Ask players to report:

- RimWorld version
- Mod version
- Active mod list and load order
- Whether Odyssey is installed
- The address used for testing
- What happened and what was expected
- Player.log or HugsLib log when an error occurs
