# RIMWORLD-STARGATE: Parallel Gates

`RIMWORLD-STARGATE: Parallel Gates` is a RimWorld 1.6 Stargate mod prototype based on the RimGate Jaffa/Kree mod base.

It brings Jaffa content to RimWorld 1.6 and adds a playable StarGate system with manual dialing, generated destinations, return travel, incoming Stargate events, and developer tools for testing.

## Quick Install

1. Download or clone this repository.
2. Open the mod folder from the repository.
3. Copy the whole mod folder into:
   `C:\Program Files (x86)\Steam\steamapps\common\RimWorld\Mods`
4. Start RimWorld.
5. In the Mods menu, enable:
   - `Harmony`
   - `Humanoid Alien Races`
   - `RIMWORLD-STARGATE: Parallel Gates`
6. Restart the game when RimWorld asks for it.

Detailed installation help in English and Czech is in [HOWTOINSTALL.md](</C:/Program Files (x86)/Steam/steamapps/common/RimWorld/Mods/Rimworld@Gate/HOWTOINSTALL.md>).

## Requirements

- RimWorld 1.6
- Harmony
- Humanoid Alien Races

## Current Highlights

- RimWorld 1.6 support
- Jaffa race, factions, pawn kinds, armor, helmets, weapons, sounds, and names
- Czech localization for the mod content updated so far
- Auto-spawned home StarGate and control panel on a new game
- Manual 7-symbol dialing UI
- Address book and galaxy browser
- Stable saved addresses and generated destinations
- Return travel to the home world
- Incoming Stargate arrivals:
  - raids
  - traders
  - ally / visitor groups
- DevTools support for Stargate incident testing
